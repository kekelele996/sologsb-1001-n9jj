# 多语言字幕与配音脚本对齐工作台

一个基于浏览器本地数据的字幕与配音脚本校对工作台。支持导入 SRT 或“角色：台词”格式的剧本文本，从时间轴和逐条列表两个视角维护双语台词。

## 功能

- 导入 SRT / 剧本、编辑原文与译文、修改角色、语速、关联术语和校对状态。
- 按时间码拆分、与下一条合并、上下移动及删除台词。
- 时间轴缩放、角色筛选、全文搜索，以及键盘逐条校对。
- 快捷键：`J` / `K` 切换台词，`A` 或 `S` 确认，`X` 标记疑问，`L` 锁定；`Ctrl/⌘ + Z` 撤销，`Ctrl/⌘ + Y` 或 `Ctrl/⌘ + Shift + Z` 重做。
- 自动检查前后语气、称呼和角色切换；本地术语表检查漏译或术语偏差。
- 完整撤销重做、版本快照与恢复、SRT 导出。
- 简体中文、英文、日文界面切换，菜单、快捷键提示和错误信息同步变化。
- 数据保存在 IndexedDB。使用 schema 版本号与迁移（旧稿升级后打开可继续编辑）、BroadcastChannel 和**字段级三方合并**处理多标签页写入：晚保存的标签只合入自己改过的字段，不会整篇覆盖别人；同一字段两边都改且不一致时挂起，由人工选择归属。
- **工作台 / 配音棚字段分治**：译文、时间码、语速、角色、术语和校对状态归工作台；每条台词的实录起点、实录时长和替班归配音棚（`cue.studio`），两边互不覆盖。
- **配音棚回传对账**：按时间码（±0.6s 容差）把实录对到台词；缺少、多出或一个时间码对上多条（错位）的记录挂起，等人指定归属或忽略。失败批次保留在队列中，可从配音棚侧重试。
- 离线仍可编辑，刷新后自动恢复。

## 技术栈

- Vue 3 + Vite + TypeScript
- Pinia
- Element Plus
- IndexedDB + BroadcastChannel

## 本地开发

```bash
npm install
npm run dev
```

开发服务器端口由 Vite 输出。宿主端口映射仅由根目录端口表和 Docker 命令负责，源码不硬编码宿主端口。

## 生产构建

```bash
npm install
npm run build
npm run preview
```

## Docker

```bash
docker build -t sologsb-1001 .
docker run --rm -p 10001:80 sologsb-1001
```

容器内的 nginx 监听 `80`。访问 `http://localhost:10001`。

## 数据说明

文档、版本快照和修改历史保存在浏览器 IndexedDB（数据库 `sologsb-1001`，schema v2）。运行时不依赖后端，首次打开会写入可交互示例数据。旧版（v1，无 `schemaVersion`）数据在首次读取时自动迁移：原先内联在台词上的实录时长/替班字段搬到独立的 `cue.studio` 归属域，升级后可直接继续编辑。

配音棚回传为纯文本，每行一条，字段用 `|` 或制表符分隔：

```
时间码 | 实录时长(秒) | 替班（可空） | 备注（可空）
00:00:00,000 | 4.05 |  | 棚内首条
```

回传批次、挂起队列和忽略指纹都存在文档的 `studio` 域内。逻辑层（合并、对账、迁移）不依赖浏览器，可用以下方式跑验证：

```bash
node_modules/.bin/esbuild scripts/verify.mts --bundle --platform=node --format=cjs --outfile=/tmp/verify.cjs && node /tmp/verify.cjs
```
